# Mercedes-Benz 🚘

**Responsive HTML & CSS Website**

Mercedes-Benz is a responsive front-end demo project created as a practice exercise after completing an HTML & CSS
course.
The goal of the project was to apply modern layout techniques, responsive design principles, and clean CSS structure
while recreating a premium automotive brand website.

The project focuses on **layout, typography, spacing, and responsiveness**, without relying on frameworks or heavy
JavaScript.

## 🧠 About the Project

This project is a static marketing website inspired by the official Mercedes-Benz brand.
It presents vehicle models, brand values, and call-to-action sections in a clean, modern, and fully responsive layout.

The main purpose of the project was **learning and practice**, not commercial use.

---

## ✨ Website Features

* Clean and semantic HTML5 structure
* Premium, minimal visual style inspired by Mercedes-Benz
* Vehicle models section with consistent layout
* Statistics / brand highlights section
* Image gallery
* Call-to-action section
* Smooth scrolling navigation
* Accessible images with meaningful `alt` attributes

---

## 🛠️ Tech Stack & Implementation

The project was built using:

* **Semantic HTML5**
* **Modern CSS3**
* **CSS Grid & Flexbox** for layout
* **Responsive units (`rem`, `%`)**
* **Media queries** for multiple breakpoints
* **Well-structured CSS architecture**
* **Careful color usage** and consistent spacing
* **Accessible images** using `alt` attributes
* **Basic JavaScript** for smooth scrolling and small interactions

No frameworks or libraries were used — everything is written in **vanilla HTML, CSS, and JavaScript**.

---

## 📱 Responsive Design

The website is fully responsive and optimized for:

* Mobile devices
* Tablets
* Laptop and desktop screens

Special attention was given to:

* typography scaling with `rem`
* layout behavior at different screen widths
* readability and spacing on smaller devices
